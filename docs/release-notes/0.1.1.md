Players on any `0.1.x` can play together: this release changes neither the IPC nor the Peer protocol. Only the Helper changed; the DLL is as in 0.1.0.

This is a measurement release. It doesn't make internet games faster yet; it records what makes them slow so the fixes can follow.

**What's new**

- Each friend's row shows **Direct** or **Relayed (slower)**, so you can see whether your connection to that friend goes straight or through a relay.
- The Helper's log now has a line for every path change, every Turn sync and the game start.
- The Helper accepts `wtp.exe` as a game executable, next to `thinker.exe` and PRACX.
- Testers can record a game's traffic with `DATALINK_CAPTURE` (off by default). `DATALINK_RELAY_ONLY=1` forces a Relayed connection, so a tester can record that kind of game. Neither is for everyday play.

**Testers: what to send back**

- Send the Helper's **log** after a game, especially a slow one.
- Send a **capture** only when asked. When we ask, start the Helper with `DATALINK_CAPTURE` set to a folder and send the `.jsonl` file from it. See [docs/traffic-capture.md](https://github.com/BlinkingApe/datalink-mp/blob/main/docs/traffic-capture.md).
