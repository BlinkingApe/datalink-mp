Players on any `0.1.x` can play together: this release changes neither the IPC nor the Peer protocol. Only the Helper changed; the DLL is as in 0.1.0.

This release fixes two problems with reconnecting to a friend. Both fixes are on by default; there is nothing to switch on.

**What's fixed**

- The reconnect to a friend now starts as soon as the loss is seen. It is no longer lost if you click **Host Game** or **Join Game** just after the drop.
- After a friend's connection is lost and re-dialled, messages sent straight to that friend reach them again. This mattered most in games of three or more, between two Joiners.

**Testers: what to send back**

- Send the Helper's **log** after a game, especially one where a connection dropped.
- Send a **capture** only when asked. The capture's analysis lines and the Helper's log lines are unchanged from 0.1.1. When we ask, start the Helper with `DATALINK_CAPTURE` set to a folder and send the `.jsonl` file from it. See [docs/contributors/traffic-capture.md](https://github.com/BlinkingApe/datalink-mp/blob/main/docs/contributors/traffic-capture.md).
