Players on any `0.1.x` can play together: this release changes neither the IPC nor the Peer protocol. Only the Helper and the DLL's game fixes changed.

**What's new**

- **Classic faction colors in Alien Crossfire.** In `terranx.exe` (including under `wtp.exe`), every faction should now wear its own colors on flags, base labels, minimap dots and borders. Before, the fix only worked in the original game, so an Alien Crossfire game could show a faction in someone else's color (for example the Pirates in the Believers' orange). **This is new and has not been tried in a real game yet.** It is on by default; set `SMAC_NO_CLASSIC_COLORS=1` to turn it off. See [docs/players/faction-colors.md](https://github.com/BlinkingApe/datalink-mp/blob/main/docs/players/faction-colors.md).
- **The game carries on when the host leaves mid-game.** The remaining players' games now continue with a new host instead of exiting to the desktop, including when the host's Helper stops. This is also untried in a real game.
- **Log-collection script.** The Windows zip and the Linux tarball include `datalink-mp-collect-logs`, which starts the Helper and the game with logging on. See [docs/players/collecting-logs.md](https://github.com/BlinkingApe/datalink-mp/blob/main/docs/players/collecting-logs.md).
- The DLL log now names the game binary it found (`terran.exe` or `terranx.exe`) and says plainly when a fix isn't available for it, instead of logging an "unknown binary version" error.

**Testers: what to send back**

- Send the Helper's **log** and the game's **DLL log** after a game.
- For colors: the DLL log's `classic colors` lines (one per seat), plus screenshots of the same map area from two machines, if a faction looks wrong.
- For the host leaving: say whether the other games carried on, and send the logs.
